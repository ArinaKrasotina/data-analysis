## 📌 Описание проекта

Данный проект представляет собой комплексное решение по автоматизации сбора, обработки и анализа данных маркетплейса за 2023 год.

Реализован полный цикл работы с данными:
- сбор данных из API  
- построение ETL-процессов  
- хранение в PostgreSQL  
- аналитика и визуализация в Metabase  
- формирование бизнес-рекомендаций  

Проект ориентирован на применение в e-commerce и демонстрирует подход end-to-end аналитики.

**Ключевые цели проекта:**
- Автоматизация сбора и хранения данных  
- Анализ продаж и оптимизация ассортиментной матрицы  
- Анализ клиентского поведения и рост LTV

## 🔍 Проверка гипотез

**Ассортимент:**
- H1 — выручка зависит от количества заказов → ✅ подтверждено  
- H2 — выручка сконцентрирована в топ-товарах → ✅ (20% = 38.56%)  
- H3 — есть неэффективный “длинный хвост” → ✅ (20% = 4%)  
- H4 — заказы крупные → ✅ (B2B-модель)  

**Клиенты:**
- H1 — основной отток после первой покупки → ✅ (Retention = 14.94%)  
- H2 — база неоднородна → ✅  
- H3 — LTV зависит от частоты → ✅  
- H4 — потери от оттока значимы → ✅ (13.5%)

## 💡 Ключевые инсайты

1. **Неэффективный ассортимент**  
   20% товаров дают лишь ~4% выручки → потенциал оптимизации  

2. **Критический ранний отток**  
   85% клиентов не возвращаются после первой покупки  

3. **Высокий потенциал retention**  
   Возврат 20% клиентов → **+45 млрд ₽ выручки**  

4. **B2B-поведение клиентов**  
   Глубина чека ≈ 30 товаров → рост через объем заказа  

5. **Рост LTV через удержание**  
   +1 месяц lifetime → **+47% к LTV**

## 🚀 Итоговая бизнес-логика

Рост маркетплейса достигается за счет:

- увеличения retention  
- оптимизации ассортимента  
- роста объема заказа  

👉 Это позволяет значительно увеличивать выручку без пропорционального роста затрат на привлечение.

## 🔧 Инструкция по развертыванию

### 1. Установка
git clone https://github.com/your-repo/marketplace-etl.git  
cd marketplace-etl  
pip install -r requirements.txt  

### 2. Запуск

**Историческая загрузка:**
python etl.py history  

**Ежедневное обновление:**
python etl.py daily  

### 3. Cron

0 7 * * * cd /home/ubuntu/marketplace-etl && /usr/bin/python3 etl.py daily >> /var/log/etl.log 2>&1
