# Статистический анализ данных Wildberries

Проект посвящен глубокому анализу продаж на маркетплейсе Wildberries с использованием методов математической статистики и эконометрики для оптимизации прибыли и маркетинговых стратегий.

## Цель проекта

Провести комплексный анализ данных (EDA), выявить многофакторные зависимости и проверить статистические гипотезы о влиянии маркетинговых инструментов (акции, реклама) и операционных показателей на чистую прибыль.

## Ключевые результаты анализа

*   **Акции и прибыльность:** Тест Манна-Уитни подтвердил статистически значимое (p < 0.05) **снижение медианной прибыли** при участии в акциях. Текущая стратегия скидок не компенсируется объемом продаж.
*   **Эффективность рекламы:** ANOVA и регрессионный анализ выявили слабую отдачу от рекламных инвестиций. Средний бюджет — **1365 руб.**, при этом сверхзатраты (до **37 100 руб.**) имеют убывающую предельную доходность.
*   **Эластичность спроса:** Корреляция Спирмена подтвердила значимую отрицательную связь между ценой и заказами. Выявлен оптимальный ценовой диапазон в районе **2300 руб.**
*   **Драйверы прибыли:** Множественная линейная регрессия определила **процент выкупа** как наиболее значимый фактор, напрямую влияющий на финансовый результат.

## Этапы работы

1.  **Предобработка:** Очистка данных, преобразование типов (проценты в float), обработка пропусков с сохранением распределения (медианная импутация).
2.  **EDA:** Анализ распределений (выявлена сильная асимметрия прибыли, медиана **913 руб.** vs среднее **4630 руб.**), поиск аномалий и визуализация корреляций.
3.  **Статистическое тестирование:**
    *   Проверка нормальности (Шапиро-Уилк).
    *   Сравнение групп (Манн-Уитни для акций).
    *   Анализ категориальных данных (Хи-квадрат для связи акций и выкупа).
4.  **Моделирование:** Построение модели множественной регрессии для оценки вклада каждого фактора в итоговую прибыль.
5.  **Бизнес-рекомендации:** Формирование стратегии по оптимизации рекламного бюджета и пересмотру акционной политики.
