# Статистический анализ данных Wildberries

Проект посвящен глубокому анализу продаж на маркетплейсе Wildberries с целью оптимизации прибыли и маркетинговых стратегий.

## Цель проекта

Провести исследовательский анализ данных (EDA), выявить скрытые зависимости и проверить статистические гипотезы о влиянии различных факторов на ключевые бизнес-показатели.

## Ключевые выводы

- Акции статистически значимо не влияют на количество заказов (p-value > 0.05)
- Рекламный бюджет слабо коррелирует с заказами (r = 0.30)
- Распределение прибыли сильно скошено, большинство операций приносят небольшую прибыль или убытки

## Стек технологий

- Python: Pandas, NumPy
- Статистика: SciPy (t-тесты, корреляция Пирсона)
- Визуализация: Matplotlib, Seaborn

## Этапы работы

1. **Предобработка**: очистка данных, работа с пропусками и типами данных
2. **EDA**: анализ распределений, выбросов, связей между метриками (прибыль, заказы, реклама, цена)
3. **Проверка гипотез**: оценка влияния акций, рекламы, цены и процента выкупа на продажи
4. **Выводы**: формирование бизнес-рекомендаций на основе данных
