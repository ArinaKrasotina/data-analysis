# A/B-тест: влияние позиции рекламы в ленте

## О проекте
Сравнение двух вариантов размещения рекламы:
- **Группа A (контроль):** органика → реклама
- **Группа B (тест):** реклама → органика

**Цель:** оценить влияние на доход и поведение пользователей.

## Результаты

| Метрика | Изменение | p-value | Значимо |
|:--------|:---------:|--------:|:-------:|
| RPM | +19.5% | 0.55 | ❌ Нет |
| Paid CTR | +13.8% | 0.28 | ❌ Нет |
| Organic CTR | **-52.4%** | <0.001 | ✅ Да |
| Views per session | **-3.9%** | 0.014 | ✅ Да |

**Итог:** ❌ Не внедрять. Рост дохода статистически незначим, падение вовлечённости — значимо.
